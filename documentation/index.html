Jobpath Next.js

Everything you need to run, customize and maintain the Next.js conversion of the Jobpath HTML template.

The project preserves the original Jobpath design, fonts, icons and CSS while using React components, Next.js routing and shared interactive controllers. It does not use Tailwind CSS.

Current scope: this is a frontend template with browser-based previews. Authentication, server-side account data, message delivery, file uploads, billing and public job publishing are not connected to production services. Dashboard charts and sample rows are demonstration data.

02 / GET STARTED

Installation & commands

Use Node.js 20.9.0 or newer and npm. The minimum Node version comes from the installed Next.js package. Google Chrome is required for the configured browser tests.

  1. Open a terminal in the jobpath-nextjs project folder.
  2. Install the locked dependencies and start the development server.
npm ci
npm run dev

Open http://localhost:3000. Changes to components and styles update through the development server.

On Windows PowerShell, use npm.cmd and npx.cmd if script execution policy blocks the standard commands.

CommandPurpose
npm ciInstall the versions recorded in package-lock.json.
npm run devRun the Next.js development server.
npm run buildCompile and type-check the production application.
npm run startServe the existing production build.
npm run lintRun ESLint.
npm run verify:assetsCheck referenced assets and the HTML-free application source convention.
npm run test:e2eRun Playwright tests against a production server on port 3127.

05 / DATA

Content & search

src/data/catalog.json contains 20 jobs, 10 employers, 11 candidates and 9 blog records. src/data/details.ts defines the shared record type and lookup helpers.

  1. Find the record under its kind: job, employer, candidate or blog.
  2. Update its title, description, location, tags, image and related fields. When adding a record, copy a complete record of the same kind and keep all required fields.
  3. Give new records a unique object key and matching slug. Set kind to the correct record family.
  4. Place new assets in public/assets and reference them with a URL such as /assets/img/example.webp.
  5. Check listing and detail views, run asset verification, and rebuild for production.

Change default detail records through defaultSlugs in details.ts. Home-page section text and images can also be embedded directly in page-sections; changing the catalog does not automatically replace every home-page element.

07 / PERSISTENCE

Browser storage

Preview data lives in localStorage for the current browser and origin. It survives page reloads but does not synchronize across devices, accounts, browsers or different ports. Clearing site data removes these drafts.

Storage keyContents
jobpath:shortlistSaved shortlist records.
jobpath:applicationsLocal application previews.
jobpath:followingFollowed company records.
jobpath:draft:<pathname>Saved form values for a route.
jobpath:dashboard:jobsEmployer job drafts.
jobpath:dashboard:meetings:<role>Meeting drafts separated by account role.
jobpath:dashboard:<pathname>:…Additional fields, row edits/removals, read contacts and recipient message drafts.

For a targeted reset, open browser Developer Tools → Application → Local Storage, select the app origin and remove only the relevant jobpath: key. Export any drafts you want to keep before deleting them.

The site loads compiled CSS. There is no Sass build script in package.json; changing SCSS alone does not update the served stylesheet. Use CSS overrides or add a deliberate Sass compilation workflow.

Hover & motion

Shared hover timing is configured through --hover-duration and --hover-easing in globals.css. The current duration is 280 ms. The reduced-motion media query keeps motion minimal when requested by the visitor.

Route scrolling

The root <html> includes data-scroll-behavior="smooth" for Next.js scroll behavior handling. Keep it when using global smooth scrolling. Route lifecycle behavior is managed in ThemeController.tsx.

09 / RESPONSIVE MENU

Mobile navigation

src/app/components/MobileNavigation.tsx reproduces the original Jobpath MeanMenu appearance using React state. It uses the existing theme CSS classes with bordered rows, right-aligned plus/minus toggles and nested submenu levels.

  • Top-level groups: Home, Browse Jobs, Employers, Candidates, Pages and Contact.
  • Edit the menus array to change labels, destinations or submenu groups.
  • Links use next/link; buttons expose aria-expanded and aria-controls.
  • Closed submenus are inert, so their links cannot receive keyboard focus.
  • The offcanvas shell, logo, account buttons and social links are in page-sections/about/MobileMenu.tsx.

Bootstrap controls the offcanvas panel. The original MeanMenu jQuery script is not initialized for this React menu. Avoid initializing it in parallel, which would duplicate the navigation.

12 / RELEASE

Production setup

On a Node.js host, install the locked dependencies, produce a build and run the application server:

npm ci
npm run build
npm run start -- --port 3000

Use the host's process manager and HTTPS routing for the running server. The repository is not configured with output: "export"; do not deploy it by uploading only an HTML file or the public directory.

This guide can be opened directly as documentation/index.html. It is not an application route and is not automatically served by Next.js.

Connecting real services

  1. Add authentication and authorize account-specific reads and changes on the server.
  2. Store jobs, profiles, applications, messages and meetings in a database.
  3. Replace browser-preview operations with validated server actions or API endpoints.
  4. Add file storage, message/email delivery and a payment provider for the relevant features.
  5. Replace sample analytics and verify complete user flows against the connected services.

The current frontend preview does not require a configured backend environment file. When adding services, keep private credentials on the server; use NEXT_PUBLIC_ only for values intended to be visible in the browser.

13 / HELP

Troubleshooting

PowerShell says npm.ps1 cannot be loaded

Use npm.cmd run dev or npx.cmd playwright test. This avoids changing the machine's execution policy.

Production start says no build was found

Run npm run build successfully before npm run start or the Playwright suites.

Playwright cannot find Chrome or start the server

The configuration explicitly uses channel: "chrome". Install Google Chrome, confirm port 3127 is available, and check the platform-specific npm.cmd test-server command.

A menu or slider initializes twice

Check for legacy global scripts or a second plugin initializer. React controllers already manage initialization and cleanup. Do not load the original main.js as an additional application script.

A selected file disappears after reload

File selection is session-only. The browser draft system does not upload or retain the file itself; connect file storage for permanent uploads.

My draft is missing on another browser or port

Local storage belongs to the browser and origin. Development, production and different localhost ports have separate storage. These previews do not synchronize through an account.

Next.js warns about missing data-scroll-behavior

Keep data-scroll-behavior="smooth" on the root <html> in src/app/layout.tsx when global smooth scrolling is enabled.

An image or font is missing

Run npm run verify:assets. Confirm the file exists in public and that application URLs start with /assets/, without the public prefix. Check filename case on case-sensitive hosts.

Editing an SCSS file has no visual effect

The browser loads compiled CSS, and no Sass watcher is configured. Update the served stylesheet or application CSS overrides, or configure a Sass build step.
